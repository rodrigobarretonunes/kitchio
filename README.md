# 🍳 Kitchio

Kitchio is a personal recipe management API built with FastAPI.  
The goal of this project is to practice backend development with a clean architecture, focusing on scalability, organization, and real-world workflow practices.

---

## 🚀 Current Status

The project is still in early development.  
So far, the focus has been on setting up a solid development environment and workflow structure.

### ✅ Completed so far:
- FastAPI project initialized
- Development environment configured
- Task automation using Taskipy + uv
- Basic project structure created
- Jira configured for task management and workflow tracking

---

## 📊 Workflow & Planning

To simulate a real-world development environment, the project is being managed using Jira.  
This helps structure tasks, improve planning, and simulate collaboration practices used in professional teams.

## 🎯 Goal of the Project

The goal of Kitchio is to evolve into a complete backend system for managing recipes, including:

- User authentication
- Recipe creation and management
- Clean modular architecture
- Scalable API design
- Real-world development workflow (tickets, branches, planning)

---
